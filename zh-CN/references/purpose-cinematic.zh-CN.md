# 目的：电影感短片

和模式一起在开头选定（`SKILL.md` 的 "First questions"）：模式决定工作做到多深，目的决定这是一部什么样的片子。电影感短片是一个故事、一种情绪或一件艺术品，它应该看起来是**拍出来的，不是渲染出来的**。共享规则留在各自的文件里、原样适用：运动（`motion.md`）、镜头词汇（`camera-moves.md`）、文字（`typography.md`）、声音同步（`sound.md`）、钩子、每镜一个动作和统一感（`SKILL.md` Hard rules、`quick-mode.md` §7）、检查（`engine.md` §4–5）。

## 2. 电影感的一遍处理

四层用来洗掉干净的 CG 感。每一层单独看都很微妙；叠在一起，画面才读起来像被拍下来的。主体在其中始终保持可读（`looks.md` §5）。

**其中三样由用户决定，默认关闭：** 运动模糊（a）、印刷曲线（b）和片门抖动（d）。Quick mode 把它们显示为导演卡片上的一行（用户用普通话语开哪个都行；不另设问题）。Film mode 在风格帧处问一个多选问题，每项附上几个字的成本："Hareket bulanıklığı / Motion blur (hızlı planlarda; o planların render süresi × 6–8)"（运动模糊／快镜头；这些镜头的渲染时间 × 6–8）· "Baskı rengi / Print tone (yumuşak siyahlar, filmsi ton)"（印刷色调／柔和的黑，胶片味）· "Film titremesi / Gate weave (projektör gibi hafif kayma)"（片门抖动／像放映机一样轻微漂移）· "Hiçbiri ★"（都不要）。镜头性格（c）、颗粒和摄影师的惯性（d）属于手艺，留在 look 里；只有故事需要时才上雾（d）。

### a. 运动模糊，180° 快门

- **是什么：** 每一帧是 6–8 个子帧的平均，这些子帧分布在 180° 快门张开的那半帧区间里，以该帧为中心。快速运动会像胶片摄影机记录的那样拖成一片；慢动作保持清晰。
- **只用在有东西动的地方：** 两个 starter 都先用 64 px 比较首末子帧；没有东西动的帧只保留一次清晰绘制，所以模糊只在动起来的帧上花渲染时间，而不是整个场景或镜头。
- **用在哪儿：** 只用在动得快的地方：甩镜、冲击、快速横摇和横移、掠过的物体、雨、火星。Quick mode：场景上加 `blur: true`。Film mode：该镜头的 capture 参数里 `samples=8`（或影片 look 里的 `render.motionSamples`）。
- **渲染时间：** 每个采样就是多一次绘制，所以 8 个采样的场景大约要 8 倍时间。**先在一个镜头上测试：** 分别渲染它最快的那一秒，带模糊和不带（Quick mode 用 `shutter=0`，Film mode 用 `samples=1`），在时间条上比较（`qc.py strip`），把每帧耗时写进 `STATE.md`，然后定下采样数：只需要柔和拖影的动作用 6，甩镜和冲击用 8。
- 子帧始终留在自己那个场景里，所以硬切绝不会把两个场景混在一起。甩镜转场本来就会拖出自己的复制层。

### b. 胶片影调

- 一条胶片色调曲线，加上一条由工具包自己做的印刷式曲线（不用第三方 LUT 文件）：**抬起的黑位**（最暗的值停在黑以上 3–4%）、大约从 72% 开始的**柔和高光滚降**，让白色缓缓收住而不是切掉，加一点 S 形对比，再加一道轻分离（高光偏暖，阴影偏冷）。
- Quick mode：`FINISH.tone`（在 `film.html` 里做的逐通道 1D 查找表，通过 SVG 滤镜应用）。Film mode：影片 look 里 `post.tone: 'AGX'` 加 `post.print: { lift: 0.035, knee: 0.72, contrast: 0.12, split: 0.02 }`（同一条曲线，在 `looks.mjs` 里）。
- 调色板：画面里没有纯黑也没有纯白；最亮的元素停在肩部之下。
- 在海报缩略图上检查：最暗区域读起来是有细节的深灰黑，最亮的高光保持住形状（`qc.py bright`）。

### c. 镜头性格

- **浅景深，逐镜头选，**依据这一镜的读法：一个平面清晰，注意力移动时做焦点转移（Quick：`plane()` 配 `CAM.rackFocus`；Film：pmndrs `DepthOfFieldEffect` 配 `camera.mjs` 的 `rackFocus`）。
- **椭圆散景**（变形宽银幕的感觉），作为当风格需要时的选项：失焦高光画成比宽高约 1.3–1.6 倍的椭圆。
- **轻微色差**，只朝画面边缘（`post.chromatic` 0.3–0.8；在 Canvas 里是边界附近最多 1 px 的红蓝错位副本）、**轻微桶形畸变**（直线在四角弯曲不超过 0.5%）以及**光晕**：只在最亮的边缘周围一圈暖红橙的光（Film：染暖的高阈值泛光；Quick：最亮形状的模糊、暖色、低透明度副本）。
- 这些都不该被单独注意到。

### d. 不完美层

- **动态颗粒：** 逐帧带种子，两个 starter 里已经有了（`grain()`、`post.grain`）。
- **片门抖动：** 整帧漂移不到约 1 px，每帧都换新的、带种子（Quick mode 是 `FINISH.weave`，Film mode 是 `post.weave` 或 URL 参数 `weave`）。画面文字和标签画在屏幕空间，保持稳定。
- **当故事有雾或体积光时：** 密度由缓慢噪声调制，低处和远处更厚，缓慢漂移；绝不是一片平的、均匀的雾。没有它们，片子也不损失什么。
- **一个摄影师：** 运动带着惯性开始，带着一点点过冲收住（`EASE.inertia`、`MOTION.spring(τ, 0.7)`）；手持漂移经过低通滤波（`CAM.handheld`、`camera.mjs` 的 `handheld`），绝不是逐帧抖动。

## 3. 镜头词汇

从 `camera-moves.md` 取运动，卡在卡片的速度上：一次朝揭示缓缓推近，一次跟着主体走的推轨，一次为尺度而起的升降机，一次把注意力挪开的焦点转移，一个撑住重量的定格画面。每个运动在这一镜的读法里都有理由。大动作（推拉变焦、速度坡度、定格）各至多一次；甩切和撞切只在故事跳跃的地方用。

## 4. 声音身份

环境声主导：每个空间一层底噪撑着整部片子，拟音贴近且真实，音乐是卡片点名的那套，一个标志性声音每次回来都变了（`sound.md` §1–3）。只有想法需要旁白时才加旁白。

## 5. 关口与检查（在共享检查之外补上）

- **不许走模板捷径：** 电影感短片是为它的故事搭的，所以工具包的脚手架绝不上屏。示例场景删掉，starter 的测试场景只用来测 look，预设或风格配方要换上影片自己的调色板和有动机的光，抽象形状绝不能代替主体（除非用户要的就是抽象片）。每一张静帧都用一个问题检查：它能属于另一部片子吗？如果能，就在用户看到之前重建。
- **静帧：** 最初的进度静帧（Quick）或风格帧（Film）展示主体在它自己的世界里，按场景布光，带着选定的收尾。
- **整片渲染之前：** 选了运动模糊，就先做上面那个单镜头运动模糊测试，并记录渲染时间。
- **渲染之后：** 快速场景的时间条：拖影顺滑，没有卡顿，没有重影。
- **标题卡**（`typography.md` §8）：由 Art of the Title 的参考和实测的文字方向塑形；在音乐的一个乐句上揭示；文字 QC 照常适用。
- **纪录片和讲解片：每一句台词都站在一个画面上。** 一句被念出的事实要配它所在之地的画面：法律有一座厅堂，一个决定有一栋建筑，一份条约有它印出来的纸页，一个数字有它对应的物件或人。问每一句抽象的话"这件事发生在哪里"，并把它呈现出来。黑屏只作标点：1 秒以内，用来强调（`make.py` 会标出片内超过 1 秒的黑屏）。
- **一个画面只用一次。** 一张档案照片、一张地图或一个参考出现两次，就等于告诉观众素材见底了；不同的记录（每页报纸各有自己的日期）才像做过研究。只有作为卡片上点名的回扣时才允许重复（开场的画面在结尾回来）。
- **冷静复看：** 它看起来像被拍出来的吗？点名任何仍然读起来像干净 CG 的帧（死黑、切掉的高光、均匀的雾、机器般的摄影机运动），并修掉。
