# 画面内的运动：东西怎么动

`camera-moves.md` 讲摄影机。这个文件讲摄影机看着的东西：主体、物体、文字、标签和 UI。绝大多数"电脑画出来的"运动都来自四个习惯：所有东西一起动、运动以恒定速度跑、东西说动就动说停就停、以及每个部分都在同一帧停下。下面这些规则就是用来拆掉它们的。

时间以秒计，括号里是 24 fps 下的帧数（30 fps 乘以 1.25）。Quick mode 里这些助手函数是 `film.html` 中的 `MOTION`；Film mode 里同样的函数在 §8。

## 1. 顺序：谁先动

- **每个时刻只有一个主角。** 每一个节拍里有一件事是主角：它要么动得最多，要么动得最早，眼睛跟着它走。配角动得更少、更慢、更小。
- **主角或揭示，二选一。** *主角：* 主角先动，环境回应它。*揭示：* 环境先安定，主角晚 0.1–0.2 s（3–5 f）到达，作为回报。
- **先因后果。** 引起变化的东西先动：先手后杯，先阵风后叶，先按键后屏幕。反应晚 2–4 帧，绝不在同一帧。
- **一个触发，一次启动。** 好几样东西回应同一事件时，它们在彼此一帧之内启动，并从事件发生的地方散开。它们可以落定在不同的时刻。
- **单一入口。** 一组东西从同一侧或同一个共同来源进入；方向混杂读起来就是噪声。
- **三分之一法则。** 三个以上运动元素同时存在时，至多约三分之一一起做主要运动。第一个收住时第三个开始。

## 2. 时长与间距

| 运动的东西 | 典型时长 |
|---|---|
| 一个小重音（一次滴答、一次眨眼、一枚徽章、一次按钮按下） | 0.12–0.2 s（3–5 f） |
| 一个标签、卡片或词进入 | 0.25–0.4 s（6–10 f） |
| 一个物体穿过画面的一部分 | 0.5–1 s（12–24 f） |
| 某个巨大、沉重或庄重的东西 | 0.8–1.5 s（20–36 f） |
| 环境生命（漂移、呼吸、闪烁） | 2–20 s 循环 |

- **距离翻倍，时间只多一点。** 两倍距离大约需要 1.3× 的时间；横穿整幅画面约需 1.8–2×。距离不同而时长相同，看起来很机械。
- **重量就是时长。** 重的东西起步慢、停得稳；轻的东西起步快、飘进位。按材质分：刚性金属 1.2× 基础时长且不过冲；橡胶 0.8× 且过冲 15–25%；水 1.5× 且约 5%；纸和卡片 1.0× 且 3–5%；烟 2× 且不过冲；玻璃 0.9× 且不过冲。
- **退场比入场短**：入场时长的 65–75%。
- **落定后停住。** 主要运动之后、下一个开始之前，给 4–6 帧的静止（只有环境生命在动），让眼睛记录下来。文字的停留见 `craft.md` §4。
- **间距就是缓动。** 观众感受到的是物体在帧与帧之间走过的距离。在时间条上检查（§7）。

## 3. 画面内东西的缓动

- **入场缓出**（快速到达、柔和落定）。**退场缓入**（轻轻起步、快速离开）。**画面内的移动进出都缓。** **循环用正弦。**
- **只有机器才线性**：传送带、时钟指针、恒定旋转、进度条、缓慢漂移。有生命的东西、被抛出的东西、下落的东西，绝不线性运动；这是僵硬运动最常见的成因。（摄影机运动另有规则，见 `camera-moves.md`；摄影机可以线性漂移。）
- **不许跳变。** 任何东西都不许从静止直接全速启动，也不许从全速直接骤停，除非风格刻意机械，或这个节拍就是一次硬击。每次启动都要有缓动或预备；每次停止都要有收势。
- **一组东西只用一套缓动。** 错落的一组共享同一条曲线；只有起始时间不同。

## 4. 拆掉僵硬感的原则

| 原则 | 怎么做 | 数字 |
|---|---|---|
| **预备** | 主要运动之前先朝反方向做一个小动作 | 主要运动的 10–20%，0.1–0.2 s（3–5 f）；短于 0.15 s 的重音跳过它 · `MOTION.anticipate` |
| **跟随与重叠** | 挂在身体上的部件（头发、布料、尾巴、电缆、阴影、卡片内部的各行）在身体之后启动、在身体之后停止，并带一点过冲 | 晚 1–4 f 启动，晚 2–5 f 停止；身体和它的部件绝不在同一帧停下 · `MOTION.at(t - lag, …)` |
| **次级动作** | 支撑主要动作的更小反应（落地后的扬尘、卡片抬起时变大的阴影、敲击后的涟漪） | 主要动作尺寸的 30–50%，在它之后 1–2 f 启动，有自己的缓动 |
| **弧线** | 有生命的东西沿曲线行进 | 在中段把直线路径弯出其长度的 5–20% · `MOTION.arc`；机器和 UI 可以有意走直线 |
| **挤压与拉伸** | 只在风格本来就属于它时用（卡通、俏皮） | 保持体积（变宽就变矮）；冲击 2–4 f，恢复 4–8 f；绝不用在写实或高级感风格里 |
| **按语气决定过冲** | 落定越过标记多远才停住 | 写实或高级 0% · 平静 2–5% · 一个重音 5–10% · 俏皮 15–25%；最有弹性的落定每部片子至多一次 · `MOTION.back`、`MOTION.spring` |
| **反向运动** | 背景回应主角 | 它朝反方向移动主角距离的 20–30%；各层约 1×（前）、0.5×（中）、0.2×（后） |
| **环境生命** | 在定住的镜头里总有东西在微微动 | 呼吸、尘埃、闪烁、摇摆：带种子、缓慢、靠近边缘；它绝不与要读的内容争夺注意 |

## 5. 用文字说清弹簧

`MOTION.spring(tau, zeta, f)` 给出阻尼弹簧在 `tau` 秒前被释放后的位置。`zeta`（阻尼比）决定过冲，`f`（赫兹）决定速度。

| 词 | `zeta` | 过冲 | 用途 |
|---|---|---|---|
| firm | 1.0 | 无 | 重量、写实、高级感 |
| soft | 0.8 | ≈ 1.5% | 平静的落定 |
| lively | 0.7 | ≈ 5% | 标签和卡片的默认值 |
| bouncy | 0.5 | ≈ 16% | 俏皮的重音 |
| elastic | 0.4 | ≈ 25% | 一个包袱 |
| rubber | 0.3 | ≈ 37% | 只给卡通用，且只一次 |

频率：大或重的东西 1–1.5 Hz，标准值 2–3 Hz，小而利索的东西 4 Hz 或更高。弹簧大约在 `0.64 / (zeta × f)` 秒内稳定（lively 在 2 Hz 时约 0.45 s）。

## 6. 错落

- **延迟：** 紧密的级联（字母、粒子）每项 1 帧，标准做法 2–3 帧（列表行、图标），戏剧性堆叠 3–5 帧。一组小物件应当在大约 0.5 s 内铺开完；更慢就读起来像一份慢清单，除非这个堆叠本身就是镜头的内容。
- **顺序：** 词和列表按阅读顺序，爆发围绕主角时由中心向外，退场时反过来，有机的东西用带种子的随机（`MOTION.stagger`）。
- **标点：** 最后一项落定时可以比其他的多一点过冲。

## 7. 踩着节拍，以及运动复看

- **落定落在提示点上。** 一次运动到达的那一帧（接触、缓动的终点）就是踩在拍子上的那一帧，所以运动要在提示点之前自己的时长开始启动，预备还要更早。声音引入和帧级精确的速度见 `sound.md` §2（原则 10）。
- **用时间条复看运动，不用静帧。** 每个关键运动：`python3 tools/qc.py strip <video> <start> <seconds> 12`（运动的每秒 12 帧），然后在每个提示点 + 0.3 s（收势处）用 `qc.py thumb` 取一张静帧。检查：
  1. 每个时刻只有一个主角；眼睛在半秒内找到它。
  2. 先因后果。
  3. 有生命、被抛出或下落的东西都不线性运动（时间条上帧间距相等就是线性）。
  4. 没有跳变：每次启动都缓动或有预备；每次停止都有收势。
  5. 挂着的部件有重叠；没有东西和它的身体同帧停下。
  6. 过冲不超出该语气的预算。
  7. 至多三分之一的元素同时做主要运动。
  8. 每次落定之后都有停留；定住的镜头仍在呼吸。
  9. 落定落在各自的提示点上。
- 把每条发现写成一行，带场景和秒数，修掉，然后重新检查时间条。在冷静复看里（`engine.md` §4），九项全过，运动分才给 2。

## 8. 助手函数

**形状、光和文字的运动**（在 Quick starter 里；Film mode 时把它们复制进场景页）：
- **形状变形：** `fillShape(g, morphShape(A, B, k), color)` 把一条闭合轮廓变成另一条；轮廓是点列，`poly.circle`、`poly.rect`、`poly.star` 或你自己的。用它做节拍之间的连接（"这个变成那个"，`craft.md` §3），`k` 取自 `MOTION.back`，带一点小小的收势。
- **光线扫过：** `lightSweep(g, x, y, w, h, k, { angle, width, strength, color: 'r,g,b', clip })` 用一条柔和的光带扫过产品、卡片或标题，只一次；揭示时的高级点缀，绝不用在循环上。
- **遮罩文字：** `text(g, S, str, x, y, size, color, 1, null, { reveal: k, by: 'word', spread: 0 })` 让整行从它自己的基线后面升起来；`by: 'char'` 配一个 spread 就把它错落开。
- **光圈：** 转场 `{ type: 'iris', dur: 0.5, at: [x, y] }` 在某一点上用一个圆形打开下一个场景（主体的眼睛、一盏灯、一个按钮）；它的 `shape: (g, cx, cy, r) => …` 选项画另一种遮罩形状。

Quick mode 在 `film.html` 里有这些。Film mode，把它们粘贴进引擎页：

```js
const clamp = (x, a = 0, b = 1) => Math.min(b, Math.max(a, x));
const MOTION = {
  at: (t, start, dur) => clamp((t - start) / dur),                       // 0..1 progress of a move
  back: (k, s = 1.7) => 1 + (s + 1) * (k - 1) ** 3 + s * (k - 1) ** 2,    // ease-out with overshoot: s 1 ≈ 4%, 1.7 ≈ 10%, 2.2 ≈ 15%
  anticipate: (k, amount = 0.15, share = 0.25) => k < share             // wind back by `amount`, then release
    ? -amount * (1 - Math.cos(Math.PI * k / share)) / 2
    : -amount + (1 + amount) * (1 - (1 - (k - share) / (1 - share)) ** 3),
  spring: (tau, zeta = 0.7, f = 2) => {                                  // damped spring after a release tau s ago
    if (tau <= 0) return 0;
    const w = 2 * Math.PI * f;
    if (zeta >= 1) return 1 - Math.exp(-w * tau) * (1 + w * tau);
    const wd = w * Math.sqrt(1 - zeta * zeta);
    return 1 - Math.exp(-zeta * w * tau) * (Math.cos(wd * tau) + zeta * w / wd * Math.sin(wd * tau));
  },
  stagger: (i, n, spread, order = 'seq', rand) => {   // 'random' needs a seeded rand: frames are functions of time        // start delay of item i of n
    if (n < 2) return 0;
    const u = i / (n - 1);
    const p = order === 'reverse' ? 1 - u : order === 'center' ? Math.abs(2 * u - 1) : order === 'random' ? rand() : u;
    return p * spread;
  },
  arc: (k, ax, ay, bx, by, bend = 0.15) => {                             // point on a bowed path from a to b
    const dx = bx - ax, dy = by - ay, o = bend * Math.sin(Math.PI * k);
    return [ax + dx * k - dy * o, ay + dy * k + dx * o];
  },
};
```

把一个带种子的生成器作为 `rand` 传入，这样随机错落在每一帧都保持一致（Quick mode 的版本用带种子的 `hash1`）。
