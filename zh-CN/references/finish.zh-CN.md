# 收尾：质量工具箱

把一个世界从插画抬进电影的那些手段。没有哪个是哪儿都挂的：每个场景只取服务于它的光线、主体和距离的那几个，卡片（Finish 行，逐场景）说明是哪些以及为什么。不服务这个镜头的手段就关掉；一个场景一个都没有，就说明为什么。这里的一切都是时间的纯函数（`engine.md`），所以一个手段绝不会在两次渲染之间闪烁。

| 组 | 手段 | 提升 | 伤害 |
|---|---|---|---|
| **光** | 一个有动机的主光（太阳、灯、窗） | 形体和情绪；交代我们在哪里 | 只有平环境光会像模型 |
| | 天光或环境光（`env`） | 与天空一致的柔和补光，真实的反射 | 让室内照着他看不见的天空 |
| | 柔和阴影 | 与地面的接触，尺度 | 默认的硬阴影读起来像 CG |
| | 接触阴影、环境光遮蔽（`ao`） | 角落、物体下方、屋子之间的重量 | 大俯拍和柔和阴天（会把它们压灰） |
| | 轮廓光或逆光 | 逆着背景的剪影 | 想在黑暗里藏神秘的场景 |
| | 实用光源（窗、灯、屏幕、火焰） | 世界里的生气，暖意 | 白天场景里它们根本不会发光 |
| | 光束、体积雾 | 空气、深度、尺度 | 干净的正午、产品清晰度、没有灰尘的室内 |
| | 反弹光与彩色补光 | 来自地面、皮肤、布料的暖意 | 图形化或扁平的风格 |
| **镜头** | 景深（`dof`） | 近景、微距、单一主体 | 宽幅风景、定场镜头、文字 |
| | 焦点转移 | 一次揭示，注意力转移 | 快速蒙太奇 |
| | 光晕、柔和高光 | 光周围的胶片暖意 | 清晰的图形化或产品风格 |
| | 泛光（`bloom`） | 灯、太阳、霓虹、火、火星 | 正午日光、白墙、正午的雪、文字 |
| | 色差 | 画面边缘的镜头性格 | 任何锐利的东西：文字、产品、UI |
| | 暗角 | 把视线留在画面里 | 扁平设计和明亮粉彩风格 |
| | 镜头光晕 | 一个刻意的太阳时刻 | 它只是装饰的任何地方 |
| **空气** | 空气透视、雾（`fog`） | 远处褪进空气里；层次 | 小空间、近处物体 |
| | 高处雾、地面薄雾 | 山谷、黎明的水面 | 干燥的沙漠正午 |
| | 粒子（尘埃、雪、花粉、水花） | 看得见的空气、静帧里的动感 | 干净的产品或图形镜头 |
| | 带飞溅的雨或雪 | 会打到表面的天气 | 只是落下而什么都没碰到的天气 |
| **材质** | 有变化的 PBR 粗糙度 | 真实表面：磨损的边缘、湿斑 | 到处一样的粗糙度 |
| | 法线或微观细节 | 近处的石头、灰泥、织物 | 在远处只会闪烁的距离 |
| | 半透明、次表面、菲涅耳 | 水母、皮肤、叶子、蜡、玻璃 | 不透明的东西 |
| | 湿度与反射 | 雨、海、打蜡的地板 | 干燥的地方 |
| | 磨损、污渍、颜色变化 | 有人住过的世界 | 玩具、黏土或一尘不染的产品风格——除非有意为之 |
| **几何** | 倒角与圆边 | 像真实物件那样接住光 | 低多边形或扁平风格——除非有意为之 |
| | 真实的零件，逐一命名 | 主体自己的每个零件都画出来 | —（永远如此：`quick-mode.md` Half size，绝不是半份细节） |
| | 实例之间的差异 | 没有两座房子、两棵树或两道波浪是一样的 | — |
| | 剪影细节 | 逆着天空也读得出的形状 | — |
| **运动** | 次级运动（布、烟、叶子、鸟） | 定格镜头里的生气 | 必须静止的那一刻 |
| | 运动模糊（`blur`） | 快速移动、旋转、速度感 | 慢镜头、文字、草稿（渲染时间） |
| | 轻微手持 | 在场感、纪录片感 | 锁定的图形化或产品镜头 |
| **后期** | 色调映射（ACES 或 filmic；`tone`） | 像胶片一样滚降的高光；默认开启 | 精确颜色：品牌色、像素画、扁平图形（`tone: 'NONE'`） |
| | 抗锯齿（`msaa`） | 干净的边缘、细线；默认开启 | 像素画和硬边复古风格（`msaa: 0`） |
| | 色彩分级 | 影片的调色板贯穿每个镜头 | — |
| | 颗粒（`grain`） | 胶片质感，掩盖色带 | 干净的图形、UI 或产品 |

**写在卡片上：** 每个场景的 Finish 行写明它的手段和理由（"S<n> <place>: <its devices and why>; no <device>: <why>"）。一个会伤害该镜头的手段，即便影片别处在用，也在那里关掉。

**第一版草稿之前：** 每个 GPU 场景都有它的主光、色调映射和抗锯齿，除非它的风格需要精确颜色或硬像素，并且带上卡片点名的手段；一个在环境光下看起来像模型的场景，不许拿给人看。
